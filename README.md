## 目前结论

- **网络层面:** 没有证据表明存在因果性的优先连接或锁定。
  - SD1.5 删库:权重不变,累积 degree 消失。删库后 SD1.5 系列需求只下降 20%;95% 的镜像使用者以前从没用过原仓库。
  - 镜像对:权重文件哈希一致的 34 对中,α = 0.02(标准误 0.16),明确拒绝 α ≥ 0.5。
- **集中度来源(静态分解):** 拟合模型重现了观测到的 Top-10 份额(0.396,观测为 0.388)。分别去掉各项后:
  - 去掉累积 degree:−19%;
  - 去掉质量代理(枢纽 FE):−25%;
  - 去掉近 30 天热度:−51%。

  因为是条件关联,degree 那一项只是 PA 贡献的上限。
- **函数形式:** degree 效应是凹的(degree 低于约 30 时斜率约 1.3,大于 100 后约 0.7),单一 α 不能概括。
- **生成式检验:** 节点质量 + 生命周期加 α = 0 时,集中度偏低(Top-10 为 0.19,真实为 0.39);加 α = 0.25 能拟合集中度,但领先者更替偏少(5 对 13)。缺的主要是批量账号的相关选择(同一工具使用同一基座)。
- **个人层面:** 有较强的锁定。混合模型中复用约占 37%,照抄模板约占 15%,集中在高经验作者和大机构作者。

详见 `reports/` 下最新的报告。

## 尚未解决的问题

1. **因果 PA 的识别:** 目前只靠自然实验(SD1.5 删库、34 个权重相同的镜像对,每对约 7 个月),样本小,置信区间约为 [−0.3, 0.3]。
2. **相关选择:** 批量账号和工具默认值让大量选择集中在同几个基座上(Qwen1.5、FLUX.1-dev)。生成模型需要加入"工具 / 流水线"层面的共同冲击,才能同时重现集中度和领先者更替。
3. **生成模型的估计:** α > 0 的情景没有重新估计节点质量 q,要估计 α 需要基于模拟的估计(例如间接推断)。
4. **随时间变化的冲击:** 例如工具切换默认仓库,配对 FE 吸收不了。
5. **P10 稳健性检验** R1、R2、R5、R7、R8 还没有做。
